# 实验2：3DGS物理驱动绑定方式对比实验

## 实验目的

对比4种将物理仿真绑定到3DGS的方法，回答核心问题：**3DGS场景做物理驱动时，哪种绑定方式最好？**

### 与实验1的本质区别

| 维度 | 实验1 | 实验2 |
|------|-------|-------|
| **核心问题** | 哪种求解器更准确？ | 哪种3DGS绑定方式更好？ |
| **对比对象** | PBD / XPBD / FEM | LBS / PartMM / SparseCP / Direct |
| **输出** | 粒子位置+能量 | 渲染图像+形变质量 |
| **研究方向** | 物理仿真 | 3DGS动画/驱动 |
| **论文关联** | 无 | GaussiAnimate, SC-GS, PhysGaussian |

## 4种绑定方式

### 1. LBS（Linear Blend Skinning）
- 来源：传统骨骼动画，大多数3DGS动画论文的baseline
- 原理：每个高斯点受多个骨骼影响，权重预分配
- 物理代理：骨骼 → LBS → 高斯点
- 参考：[3DGSAnimation.md](file:///d:/mdbooks/ImportantArticles/src/3DGSAnimation/3DGSAnimation.md)

### 2. PartMM（Part-aware Mixture Model）
- 来源：GaussiAnimate (2026)
- 原理：按部件分割高斯点，每个部件独立变换，部件间平滑过渡
- 物理代理：部件级物理 → PartMM → 高斯点
- 优势：超越LBS 17.3%（GaussiAnimate论文数据）

### 3. SparseCP（Sparse Control Points）
- 来源：SC-GS (2024)
- 原理：~512个控制点 + MLP预测6DoF变换 + LBS插值
- 物理代理：控制点物理 → MLP → 插值 → 高斯点
- 优势：紧凑表示，支持用户编辑

### 4. Direct（高斯球直接作为粒子）
- 来源：PhysGaussian (2024), PIG (2025)
- 原理：每个高斯球就是一个物理粒子，直接参与仿真
- 物理代理：高斯球 = 物理粒子
- 优势：无需绑定，物理和渲染天然一致

## 实验设计

### 场景
一个软体圆柱（类似果冻），底部固定，顶部施加侧向力。

### 自变量
- 绑定方式：LBS / PartMM / SparseCP / Direct（4水平）

### 因变量
1. **形变质量**
   - 形变平滑度（拉普拉斯能量）
   - 体积保持率（形变前后体积比）
   - 伪影程度（高斯球重叠/间隙）

2. **渲染质量**
   - PSNR（与参考渲染对比）
   - 渲染伪影数量

3. **计算效率**
   - 物理仿真时间（ms/帧）
   - 绑定计算时间（ms/帧）
   - 总时间（ms/帧）

### 控制变量
- 高斯点数量：5000
- 物理求解器：统一用PBD（排除求解器差异）
- 外力大小和方向：统一
- 渲染参数：统一

## 实验矩阵

4种绑定方式 × 3种力度（轻/中/重）= **12组实验**

## 预期结果

| 绑定方式 | 预期优势 | 预期劣势 |
|----------|----------|----------|
| LBS | 速度快 | 关节处伪影多，体积保持差 |
| PartMM | 部件级形变自然 | 部件边界可能不连续 |
| SparseCP | 紧凑，可编辑 | MLP引入额外误差 |
| Direct | 物理最准确 | 计算量大，高斯点数量受限 |
